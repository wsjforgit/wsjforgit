# Agent Reliability Maturity Matrix

0 Demo: prompt/context only.
1 Controlled: structured state and basic allowlists.
2 Production-oriented: authoritative state, durable checkpoints, idempotency, independent verification.
3 Measured: benchmarked recovery, measured routing, calibrated thresholds.
4 Governed: permission tiers, evidence provenance, drift and regression monitoring.

Moving up requires evidence, not architecture diagrams. Existing Project X1M measurements are narrow examples, not universal production benchmarks.
